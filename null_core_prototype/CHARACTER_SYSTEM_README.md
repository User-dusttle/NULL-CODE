# NULL//CORE 角色选择与战斗系统

## 新增角色
- PRISM / 棱镜：保留原有折射脉冲与交叉棱镜终结技。
- BULWARK / 壁垒：紫色六边形，145 HP、较慢移动；可吸收小型普通弹幕。E「脉冲反击」根据吸收数量提高反击伤害；Q「环形反击」清除周围弹幕并造成范围伤害。肉鸽专属构筑「绝对领域」可周期触发短暂无敌。
- SINGULARITY / 奇点：橙色三角形，90 HP、较快移动；命中与持续战斗都会积累终结技能量。E「引力井」吸引附近弹幕与敌人；Q「核心坍缩」造成范围爆发。肉鸽专属构筑「临界坍缩」与「引力透镜」。

## 选择角色
大厅点击「查看同步体资料」或系统导航里的「角色与模块」，选择角色后进入常规战斗或零域探索。选择保存于当前浏览器 localStorage（`nullcore.character`）。

## 控制
- WASD：移动
- 鼠标：瞄准 / 按住左键攻击
- Space：闪避
- E：角色主动技能
- Q：终结技（核心能量满 100% 时可用）

## 替换
请备份当前项目。可使用本压缩包中的完整项目副本测试；若合并到已有项目，请保留同一版本的 `index.html`、`css/lobby.css` 和 `js/` 模块，以免角色选择界面与模块不匹配。未更改主项目之外的文件。

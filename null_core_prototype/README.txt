NULL//CORE — RIFT PROTOTYPE 0.2

新增内容
- 零域探索路线：从大厅选择「零域探索」进入。
- 三个连续 BOSS：环形观测者、裂隙猎手、熔断主机。
- 每个 BOSS 保留三阶段战斗框架；新 BOSS 使用不同的弹幕节奏与视觉色调。
- 击败 BOSS 后可三选一强化，并选择修复 / 过载 / 回声路线节点。
- 生命值、强化构筑在本次探索内延续；全灭后可重新开始。
- 常规战斗入口仍然保留，不会强制进入肉鸽流程。

启动方式
1. 解压压缩包。
2. 在 null_core_prototype 目录打开终端。
3. 运行：python -m http.server 8001
4. 浏览器打开：http://localhost:8001
5. 大厅选择「零域探索」。

操作
WASD 移动；鼠标瞄准与持续射击；Space 闪避；E 折射脉冲；Q 棱镜终结技；Esc 暂停。

说明
这是可玩的流程原型。新 BOSS 的机制、数值与肉鸽路线仍是第一版草案，后续可按你的意见调整。现有环形观测者的三阶段和螺旋大招保留为第一战内容。

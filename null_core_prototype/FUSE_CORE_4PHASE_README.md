# NULL//CORE — FUSE-CORE 四阶段补丁

已在拆分版 JS 模块中接入 FUSE-CORE 四阶段机制。未修改 CSS/HTML，也没有更改 `?debug=1#/battle` 调试参数。

## 四阶段
- 阶段一：核心窗口每 10 秒轮转，前 5 秒开放；70% 血量进入阶段二。
- 阶段二：召唤独立弱化版环形观测者（独立血条、移动与环形弹幕）；复现体存活时 FUSE-CORE 受护盾保护，击败后可继续攻击核心，核心降至 50% 进入阶段三。
- 阶段三：召唤独立弱化版裂隙猎手（独立血条、追踪冲刺与扇形弹幕）；击败后可继续攻击核心，核心降至 30% 进入阶段四。
- 阶段四：部署 10 架无人机，每架提供 10% 减伤；全部摧毁后 Boss 永久瘫痪。攻击协议轮转：定向射击、环形弹幕、空袭、高能激光。

## 修改文件
- `js/core.js`：添加 `game.fuseDrones` 与 `game.fuseSummon`。
- `js/game-flow.js`：初始化 Boss 状态、无人机数组、四阶段 HUD 标签。
- `js/player.js`：核心伤害窗口、召唤体护盾逻辑、无人机减伤与无人机受击逻辑。
- `js/bosses.js`：四阶段转换、独立召唤体生成/更新/受伤、核心窗口、无人机生成/更新、四种攻击协议和激光。
- `js/combat.js`：每帧更新、召唤体攻击与碰撞、阶段四攻击计时、子弹优先命中召唤体/无人机、激光危险区域维护。
- `js/renderer.js`：召唤体独立绘制与血条、无人机绘制与激光预警/光束绘制。

## 运行
使用项目原来的 `index.html` 和 loader，不要把 `js/bosses.js` 覆盖成单文件版。建议先运行 `?debug=1#/battle` 检查四阶段切换与 UI，再关闭 debug 测试伤害。

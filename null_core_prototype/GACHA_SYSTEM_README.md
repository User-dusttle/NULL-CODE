# NULL//CORE 招募系统（当前原型）

- 招募资源单位命名为「招募信标」。
- 单抽消耗 160 招募信标；十连消耗 1600。
- 零域探索按击败的 BOSS 阶段发放资源：击败第 1 个 BOSS +20；击败第 2 个 BOSS再 +30；击败第 3 个 BOSS并完整通关再 +30。因此只打过第 1 个 BOSS 后失败/结束，累计获得 20；打过第 2 个后未能通关，累计获得 50；完整通关累计获得 80。
- 为兼容旧存档，旧版每个「半抽单位」会折算为 80 个招募信标，保留原有资源价值。
- 当前测试池只接入三名已有 R 级角色：棱镜、壁垒、奇点，三者概率均等。角色目前均视为已拥有，因此招募结果转化为对应专属核心。
- 每名角色最多消耗 5 个核心进行强化；满阶后重复获得的核心转换为 10 回收币。
- SSR 软保底、硬保底与 UP 规则暂未在仅含 R 级角色的测试池中启用；待高稀有度角色接入后再接入。


## SR 幻灵接入（fix13）
- 幻灵加入当前测试招募池，测试概率 5%；三名 R 级角色共享其余 95% 概率。
- 首次抽中幻灵只解锁角色，不赠送核心；重复抽中后获得幻灵专属核心。
- 幻灵初始生命值 50；基础闪避率 50%，成功闪避时按来袭弹幕伤害反伤 1.5 倍，并额外获得 3% 终结技能量。
- E「幽影」：冷却 8 秒，持续 2 秒；闪避率 100%、反伤 3 倍、每秒恢复 3 HP。
- Q「幽冥领域」：消耗 100% 终结技能量，持续 7 秒，半径 270；领域内幻灵获得强化潜行，领域内 BOSS 受到所有玩家造成的伤害提高 75%。
- 普通攻击命中仍按原系统获得终结技能量；领域本身不额外产生充能。
- E/Q 同时生效时不叠加闪避、反伤倍率或回血；反伤不会触发反伤连锁。
